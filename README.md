# Tameem Khan — Developer Portfolio

Personal portfolio of **Tameem Khan**, Software Engineer · Backend Developer · AI/ML Enthusiast.

**Live:** https://khantameem29.github.io · https://tameemkhan.netlify.app

![Portfolio preview](public/images/og.jpg)

## Tech stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- react-icons
- Deployed on GitHub Pages (via GitHub Actions) and Netlify

## Features

- Responsive layout for desktop, tablet and mobile
- Sticky navigation with active-section highlighting and a mobile menu
- Animated hero, scroll-reveal sections, and hover effects (respects reduced-motion)
- Skills, featured projects, experience, education & certifications, contact form
- Downloadable resume, SEO metadata, Open Graph image and structured data

## Run locally

```bash
npm install
npm run dev      # start dev server
npm run build    # production build to dist/
```

## Editing content

All text, links, skills and projects live in [`src/data/portfolio.ts`](src/data/portfolio.ts).
Project screenshots go in `public/images/projects/`.
